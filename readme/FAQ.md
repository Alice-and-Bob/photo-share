# 常见问题 FAQ

**Q：相机无法连接 FTP？**
A：确认相机与手机在同一热点下；FTP 须填 App 内显示的**直连 IP**（不是 `photoshare.local`），端口默认 2121、用户名 `camera` / 密码 `camera123`，并使用 **PASV 被动模式**。

**Q：浏览器打不开 `photoshare.local`？**
A：部分系统 / 浏览器对 mDNS 支持不佳，请直接用 App 内显示的 IP 地址（如 `http://192.168.43.1:8080`）。

**Q：照片没有出现在系统相册？**
A：照片经 MediaStore 写入 `DCIM/PhotoShare`，登记完成后相册会自动收录为「PhotoShare」分组，**无需任何授权**。若仍未显示，可在相册手动下拉刷新或重启媒体库扫描。

**Q：后台运行一段时间后被系统杀掉？**
A：App 已用前台服务 + 唤醒锁 + Wi-Fi 锁。请确认未「强制停止」，并在系统电池优化中将该应用设为「不受限制」。
